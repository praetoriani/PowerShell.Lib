# PowerShell.Lib Repository

Hello and welcome to my PowerShell.Lib repository.

In this repository, you'll find various PowerShell projects that I've created over time. Most of these projects came about simply because I was interested in the respective topics and wanted to know if and how I could implement them in PowerShell. Of course, I have far more scripts, code snippets, etc., than what I've uploaded and made available here. The projects I've provided here are (at least for me) something special. And that's why I decided to make these personal projects available here on my GitHub account in this repository.

Some projects are classic, purely console-based applications. Others, however, provide complete user interfaces and are fully functional applications. There are also some projects that have already been released in a fully functional version. These projects are listed below. Projects that are located in this repository but are not listed below (or do not offer a download on the release page) are sometimes still under development. These programs can be used, but may still contain bugs.

Some also use special fonts. All fonts are free, open-source fonts from Google.

## Context Menu Switcher

![Version](https://img.shields.io/badge/%F0%9F%93%8BVersion%3A%20-v1.00.01-01b300?style=flat&logoSize=auto&labelColor=545454)

**Context Menu Switcher** is a powerful PowerShell utility designed to toggle between the new Windows 11 context menu and the classic Windows 10 context menu. The script provides system administrators and power users with a simple, automated way to control which context menu style is displayed when right-clicking in Windows Explorer.

**Features**
- Toggle between Windows 11 and classic context menu styles
- Command-line parameter support for automation
- Multi-language support via JSON language packs
- Automatic Windows Explorer restart
- Administrator rights validation
- Comprehensive error handling and logging
- Registry backup and restoration capabilities

## Power.Ctrl.app

![Version](https://img.shields.io/badge/%F0%9F%93%8BVersion%3A%20-v1.00.10-01b300?style=flat&logoSize=auto&labelColor=545454)

**Power.Ctrl.app** is a user-friendly system control application that provides four essential Windows actions through a modern graphical interface:
- 🔒 **Lock workstation**
- 👤 **Log off user**
- 🔄 **Restart computer**
- ⚡ **Shut down computer**

**✨ Features**

- 🎨 **Modern Dark Mode UI** - Sleek, dark WPF interface
- 🌍 **Full Localization** - German/English with automatic language detection
- 📍 **Flexible Positioning** - Center, Lower-Left, Lower-Right
- ✅ **Confirmation Dialogs** - Security prompts before system actions
- 📝 **Optional Logging** - Detailed logging with timestamps
- 🎯 **Shell32.dll Icons** - Native Windows system symbols
- ⚡ **Robust Architecture** - Stable WPF Application management
- 💻 **Windows 11 Ready** - Optimized for modern Windows versions
