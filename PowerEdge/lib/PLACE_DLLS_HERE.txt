PLACE WEBVIEW2 DLLS IN THIS DIRECTORY
======================================

This directory must contain the following two DLL files from the
Microsoft.Web.WebView2 NuGet package before PowerEdge will start:

  - Microsoft.Web.WebView2.Core.dll
  - Microsoft.Web.WebView2.Wpf.dll

HOW TO GET THEM:

1. Go to: https://www.nuget.org/packages/Microsoft.Web.WebView2
2. Click "Download package" (.nupkg)
3. Rename .nupkg -> .zip and extract
4. Navigate to: lib\net45\
5. Copy both DLL files into this directory

ALTERNATIVELY: Run this in PowerShell in the PowerEdge root:
    nuget install Microsoft.Web.WebView2 -OutputDirectory .\nuget-packages

Then copy the DLLs from:
    .\nuget-packages\Microsoft.Web.WebView2.<version>\lib\net45\

See README.md for full setup instructions.
