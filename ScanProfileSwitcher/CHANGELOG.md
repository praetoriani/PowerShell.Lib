# ScanProfileSwitcher - Changelog

## [1.0.0] - 2025-12-20

### Added
- Initial release of ScanProfileSwitcher
- Scanner profile management with Standard and Duplex modes
- User-friendly WPF GUI application
- Profile configuration persistence via JSON
- Comprehensive error handling and logging
- TWAIN scanner profile integration
- Support for Windows 10/11

### Features
- Graphical interface for profile selection
- Automatic profile switching
- Configuration saving and restoration
- Multiple UI dialogs (error, warning, confirmation)
- Detailed error logging
- User-friendly German UI language
- Checkbox-based profile selection with mutual exclusion
- Unsaved changes detection and warning
