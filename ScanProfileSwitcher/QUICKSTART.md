# ScanProfileSwitcher - Quick Start Reference

## 🚀 Für Benutzer (60 Sekunden)

### Installation
1. Doppelklick auf **ScanProfileSwitcher** Icon auf dem Desktop
2. Fertig! ✅

### Profil wechseln
```
1. Klick auf gewünschtes Profil
2. Klick "Speichern"
3. Bestätigung ✓
4. Programm beendet sich selbst
```
