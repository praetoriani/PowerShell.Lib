# ScanProfileSwitcher - Administratorhandbuch & Installation

## 📋 Systemanforderungen

### Hardware
- **Prozessor**: Intel/AMD x86-64 (moderner Standard)
- **RAM**: Mind. 512 MB freier RAM
- **Speicher**: Min. 50 MB Festplattenspeicher

### Software
- **Betriebssystem**: Windows 10 oder Windows 11 (64-Bit empfohlen)
- **PowerShell**: Version 5.0 oder höher (standardmäßig enthalten)
- **Framework**: .NET Framework 3.5+ oder .NET 5+ (für WPF, meist bereits vorhanden)
- **TWAIN-Treiber**: Muss installiert und konfiguriert sein

## 🚀 Installation

Siehe das Installation-Installationsscript für automatisierte Bereitstellung.

## 🔧 Konfiguration

Die Konfiguration erfolgt über `config.json` im ScanProfileSwitcher-Verzeichnis.

## 📞 Support

Bei Fragen kontaktieren Sie Ihren Administrator.
